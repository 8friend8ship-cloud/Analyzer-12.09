Content OS 개인정보처리방침

Privacy Policy · Last updated: 2026-08-20

Content OS는 콘텐츠 분석, 저장, 검색, 플랫폼 연동을 제공하는 HomeDesign 서비스입니다. 본 방침은 Content OS 웹서비스 및 연결 기능에서 처리되는 정보와 이용 목적을 설명합니다.

1. 처리하는 정보

서비스는 사용자가 직접 입력한 검색어, 콘텐츠 메타데이터, 공개 플랫폼 데이터, 서비스 이용 과정에서 생성되는 작업 상태 및 저장 요청을 처리할 수 있습니다. Google 또는 기타 계정 로그인을 사용하는 경우 인증에 필요한 최소 계정 정보만 처리합니다.

2. YouTube 및 외부 API

Content OS는 YouTube 등 외부 플랫폼의 공식 API 또는 공개 데이터를 사용할 수 있습니다. 외부 플랫폼 데이터는 해당 제공자의 정책과 이용약관에 따라 처리하며, 인증되지 않은 제3자의 비공개 데이터를 수집하지 않습니다.

3. Pinterest 연동

Pinterest API가 활성화되면 사용자가 승인한 범위에서 핀·보드·콘텐츠 메타데이터를 조회하거나 저장·관리하는 기능을 제공할 수 있습니다. Pinterest 계정 권한은 OAuth 동의 범위를 초과하여 사용하지 않습니다.

4. 저장 및 캐시

일부 데이터는 브라우저 로컬 저장소에 임시 저장될 수 있습니다. 중앙 저장이 활성화된 작업은 승인된 백엔드를 통해 Google Drive, Google Sheets 또는 Content OS 데이터 저장소에 기록될 수 있습니다. API 비밀키와 OAuth Secret은 브라우저 코드나 공개 GitHub 저장소에 저장하지 않는 것을 운영 원칙으로 합니다.

5. 이용 목적

데이터는 콘텐츠 분석, 검색 결과 제공, 작업 이력 관리, 중복 방지, 저장·송호출, 플랫폼 연동, 서비스 품질 개선을 위해 사용합니다. 사용자 데이터를 광고주나 데이터 브로커에게 판매하지 않습니다.

6. 보관 및 삭제

외부 API 데이터는 해당 플랫폼의 보관 정책을 준수합니다. 사용자는 연결 권한을 철회할 수 있으며, 저장된 사용자 데이터의 삭제 요청을 할 수 있습니다.

7. 제3자 서비스

서비스는 Google, YouTube, Pinterest, Vercel 및 사용자가 연결한 기타 서비스와 연동될 수 있습니다. 각 서비스에는 해당 사업자의 개인정보처리방침이 적용될 수 있습니다.
